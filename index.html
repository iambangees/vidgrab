VidGrab

Paste a link from YouTube, X, TikTok or Facebook and download the video to your device — through a small server you own, not a stranger's ad farm.

⚙ Your download server

Browsers can't pull videos off those platforms directly — a tiny server does the fetching (it's in this project's repo, ~10 minutes to deploy free on Render or Railway, or run it on your own computer). Paste its address here once and this page is fully yours.

  1. Open the VidGrab repo → the server/ folder has everything, including a Dockerfile.
  2. Deploy it free: Render → New → Web Service → point it at the repo's server folder (Docker) → Deploy.
  3. Copy the service URL, paste it above, save. Done — fetch away.

Fair use, plainly: only download videos you own, that are yours to keep (Creative Commons, public domain, your own uploads), or where the platform offers saving. Respect creators and each platform's terms. VidGrab's page code is open; the server runs on your account and under your control. Built by Bangees.

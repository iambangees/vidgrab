⚙ Download server

Browsers can't pull videos off those platforms directly — a tiny server does the fetching. This page comes pre-connected to the project's own server, so downloads work straight away (first fetch after a quiet spell can take ~30–60 seconds while the free server wakes up). Prefer running your own? The server code is in this project's repo — deploy it and paste its address here instead.

  1. To run your own server: open the VidGrab repo → the server/ folder has everything, including a Dockerfile.
  2. Deploy it free: Render → New → Web Service → point it at the repo's server folder (Docker) → Deploy.
  3. Copy the service URL, paste it above, save. The page will use yours instead of the built-in one.

Fair use, plainly: only download videos you own, that are yours to keep (Creative Commons, public domain, your own uploads), or where the platform offers saving. Respect creators and each platform's terms. VidGrab's page code is open; the server runs on your account and under your control. Built by Bangees.
